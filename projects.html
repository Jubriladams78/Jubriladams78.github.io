Network Troubleshooting Lab (WGU D412)

Nov 2026

WGU coursework simulation in GNS3. I resolved all six simulated network and security help desk tickets with a 100% score, working with Wireshark, VyOS routers, an OPNsense firewall, Windows Server DNS, and Ubuntu and Windows clients.

The problems included a routing loop between two routers, a rogue DNS zone that redirected users to a fake site, a firewall rule that blocked access to a DMZ server, a laptop with the wrong IP configuration, an illegal FTP server found in a packet capture, and unauthorized open ports found with a full TCP scan. I asked each requester targeted questions and confirmed every fix with them before closing the ticket.

The repository documents my methods and tools only. Specific ticket answers are left out on purpose, because the simulation is a graded assessment that other students still take. Read the full walkthrough of my methods. The repository also has a command reference (commands.md).

Windows Server 2025 Home Lab

Sep 2026

A self directed lab that simulates an enterprise workflow on Hyper-V with a Windows Server 2025 domain controller and a Windows 11 Enterprise client. I deployed an SMB departmental share, gave an Active Directory security group access through NTFS permissions, and used Group Policy Preferences to map the share for users automatically.

I checked domain user access and the drive mapping with PowerShell, and fixed a client that had dropped out of the domain and a duplicate drive map entry in the policy.

Evidence: the repository documents the build and the troubleshooting along the way.

Secure Azure Ubuntu Web Server with Azure Bastion

Jul 2026

A lab from the Scarstack Solutions IT Bootcamp. I deployed an Ubuntu VM running Nginx in Azure with administration routed through Azure Bastion, a subnet level network security group, a public DNS name, and governance tags for cost tracking and ownership.

In my review after the lab I found the network security group still allowed SSH from the internet, and I documented the fix: limit port 22 to the Bastion subnet or remove the rule.

Evidence: a post lab review in the repository that records the security finding and its fix.
